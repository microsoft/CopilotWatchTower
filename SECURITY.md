## Operational security boundary

CopilotWatchTower is a local, single-operator administrator workstation. It is
not a centralized service and does not provide its own multi-user RBAC or remote
access layer. Anyone who can use the active Windows account and open its local
profile data should be treated as able to access the collected tenant evidence.

### Local data protection

- Profile databases are stored under
	`%LOCALAPPDATA%\CopilotWatchTower\profiles\<profile-id>\store.db`.
- Conversation bodies, attachment metadata, audit payloads, and raw JSON are
	plaintext SQLite data. This is required by the current FTS5 search and local
	analytics implementation.
- Client secrets, optional browser-automation passwords, and delegated MSAL
	token caches are protected with Windows DPAPI for the current user. DPAPI does
	not encrypt the SQLite content database.
- Backups and CSV/JSON exports are not DPAPI-protected by CopilotWatchTower.
	Their destination permissions, encryption, retention, and deletion are the
	operator's responsibility.

CopilotWatchTower does not send collected evidence to a project-operated
backend. It connects directly to Microsoft services. This does not suppress
telemetry, sign-in records, or audit events generated by those services.

### Authentication and remote effects

- Routine Microsoft Graph collection uses app-only client credentials.
- Purview eDiscovery uses delegated authentication and creates or reuses remote
	cases, searches, and exports. It is not read-only.
- PPAC and Dataverse collectors use browser automation to obtain Microsoft
	service tokens. Their behavior can change when Microsoft UI, MFA, or
	Conditional Access policies change.
- Some collectors use beta or unofficial endpoints. Treat them as operationally
	best-effort and review collection logs after Microsoft service changes.

### Recommended operation

- Use a dedicated, managed administrator workstation with BitLocker enabled.
- Restrict the Windows account and profile directory to authorized operators.
- Apply the least tenant permissions that support the collection paths you use.
- Do not weaken MFA or Conditional Access solely to enable unattended browser
	automation unless an approved organizational policy explicitly permits it.
- Store backups and exports only in approved encrypted locations, and remove
	them according to the organization's retention policy.
- Use CopilotWatchTower only where legal, privacy, labor, and internal policy
	authority to collect conversation content has been established.
